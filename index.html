测试用例分析工具:导入测试用例表(需含 Folder/模块、Priority、Status 等列)后自动分层拆分模块并生成全套统计。支持一次同时选中多份用例表与 BUG 导出表(含 Jira Id 列),自动识别文件类型:多份用例表(多个文件、或一个文件内多个用例 sheet)自动合并统计,多份 BUG 表自动叠加去重;也支持只选用例表(BUG 信息来自 Defects 列或用例文件内 BUG sheet)。功能:模块三级分层统计、多维筛选与分项统计、缺陷关联与台账、自动通过判定、新通过率/通过率(剔N/A)、Excel 全量导出。全部解析在浏览器本地完成,数据不上传任何服务器。
📖 口径释义:自动通过 / 新通过率 / 通过率(剔N/A)
自动通过:用例挂接 ≥1 个缺陷(关联 = Defects 列 ∪ BUG 表 Test Id 反查,合并去重),且这些缺陷 Status 全部为 Closed/关闭 → 该用例判为自动通过。原本已是 Passed/N/A 的不重复计数,只统计 Failed/Blocked/Untested 翻绿的用例;任一缺陷未关闭则不翻绿。明细见「自动通过」页。
新通过率 = (Passed + 自动通过) ÷ (用例总数 - N/A)。N/A 在分子与分母同时剔除,分子=真实通过+自动翻绿;对外汇报口径,顶部 KPI / 模块统计 / 结果分析 / 导出报表统一使用。
通过率(剔N/A) = Passed ÷ (用例总数 - N/A)。分子只计真实 Passed(不含自动通过翻绿),分母剔除 N/A;新通过率与它的差值即自动通过的贡献;分母为 0 显示 -。
示例:100 条 = Passed 60 + N/A 20 + Failed 15 + Blocked 5,其中 10 条失败用例的缺陷已全部 Closed → 自动通过 10;新通过率=(60+10)/(100-20)=87.5%;通过率(剔N/A)=60/(100-20)=75.0%。两个口径的分母都剔除 N/A;相差的 12.5 个 pct 即 10 条自动通过用例的权重。
